
# EduConnect
### Student-Centric Learning Management Portal

## About the Project
EduConnect is a student-focused learning portal designed
to help students access learning materials, manage
assignments and monitor their academic progress.

## Technologies
- HTML
- CSS
- JavaScript

## Project Modules

1. Homepage and Navigation
2. Student Login and Dashboard
3. Subjects and Study Materials
4. Assignments
5. Progress Tracker and Announcements

## Team Responsibilities

- Member 1: Homepage, common design and integration
- Member 2: Login and Student Dashboard
- Member 3: Subjects and Study Materials
- Member 4: Assignments
- Member 5: Progress Tracker and Announcements
